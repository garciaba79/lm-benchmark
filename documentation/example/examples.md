## Examples

### Test Example

This is an example of a test. You can create a test similar to this one and then place it in the scenario's root folder, a scenarios group folder or a test folder.  

For example, `/scenarios/<group>/<test>/`.  

The test can have many questions, simply name the questions like this.  

For example, `question1.md`, `question2.md`, you can add as many questions as you like.

### Inference Example

This is an example of an inference configuration.

Copy inference.json to either `/scenarios/`, `/scenarios/<group>/`, or `/scenarios/<group>/<test>/` and update the settings.
