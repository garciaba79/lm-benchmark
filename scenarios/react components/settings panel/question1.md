# Settings Panel

Build a single React and TypeScript component that acts as a settings panel with a live preview.

## Requirements
- Use only functional components and hooks. No external UI libraries.
- All form controls must be controlled inputs using `useState`.
- Include these settings:
  - Theme: light or dark (toggle or select)
  - Font size: small, medium, or large (select or radio)
  - Accent color: a color picker or text input for a hex color
- Show a live preview card that updates immediately when any setting changes. The preview should display sample text using the current theme, font size, and accent color.
- Include a Reset button that restores the default values.
- Keep everything in one file (for example `SettingsPanel.tsx`).
- Make the layout simple and usable.

## Deliverables
Produce the complete component code plus a short note on how to drop it into a standard Vite + React + TypeScript app.
